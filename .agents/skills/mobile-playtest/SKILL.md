# Mobile Playtest

Test representative narrow and tablet viewports. Verify:
- primary flows work without hover, mouse, or physical keyboard unless explicitly required;
- controls are reachable, readable, and do not overlap browser or editor chrome;
- touch targets, scrolling, orientation, safe areas, and virtual-keyboard behavior;
- gameplay controls support simultaneous or repeated input where relevant;
- layout does not clip critical status, dialogs, or actions.

Fix only within the requested scope. Recheck the affected flow and note device or browser limitations that were not directly tested.
