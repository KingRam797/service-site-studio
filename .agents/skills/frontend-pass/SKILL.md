# Frontend Pass

Before editing, identify the current design system, key screens, user goal, and existing brand assets. Improve the highest-impact issues in hierarchy, spacing, typography, color, responsiveness, interaction states, and accessibility.

Preserve functional flows and confirmed copy. Reuse existing components and tokens when sound. Avoid generic redesigns, speculative features, and asset replacement without cause. Verify affected screens at representative desktop and mobile widths and run the relevant build or checks.
